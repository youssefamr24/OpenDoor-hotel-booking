# Open Door 🏨✨

> _Your Journey, With No Hidden Doors — 100% transparent pricing and curated hotel stays with zero hidden fees._

An end-to-end UI/UX case study and developed web application built for the **Open Door** travel platform. This project addresses the core travel industry frustration of hidden cleaning, service, and tax fees by enforcing a strict upfront pricing model.

---

## ✨ Features

- **Transparent Pricing Display:** Upfront total costs with clear breakdowns and no surprise fees at checkout.
- **Curated Hotel Listings:** Filterable search and browsing experience for destinations, price ranges, and amenities.
- **Property Details View:** Comprehensive view featuring photo galleries, amenity icons, local transit info, and customer testimonials.
- **Interactive Booking Flow:** Multi-step reservation process with contact forms, stay add-ons, and dynamic price calculation.
- **Instant Confirmation:** Success feedback state validating reservation details.

---

## 🛠️ Tech Stack & Implementation

- **Frontend Structure:** HTML5, CSS3.
- **Design Tools:** Figma (Design System, Wireframes, High-Fidelity Prototypes, Responsive Layouts).
- **Architecture:** Component-based or multi-page layout mirroring the rigorous UX research and design specifications.

---

## 📄 Project Screens Included

1. **Homepage:** Hero banner, popular destinations, top nearby hotels, value proposition, and customer reviews.
2. **Hotels Listing:** Sidebar filtering system (price, location, ratings, essentials) and 20+ property grid view.
3. **Property Details:** Split layout with image gallery, descriptions, activities, area info, and a sticky booking widget.
4. **Booking Flow (Step 1):** User details, stay add-ons, promo code support (e.g., discount logic), and payment method inputs.
5. **Booking Confirmation (Step 2):** Success modal card confirming the reservation.
6. **Contact Us:** Dedicated inquiry page with form inputs.
